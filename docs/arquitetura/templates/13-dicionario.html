Dicionário de Campos

Definição canônica de cada campo. Fonte de verdade quando código, contrato OpenAPI ou diagrama divergirem.

Como ler

Cada tabela representa um tipo. Tipo lógico é o conceito (UUID, decimal, ISO 8601). Tipo .NET é como aparece no agregado. Tipo JSON é como aparece no contrato HTTP e no evento publicado. Campos com asterisco * têm regra de mascaramento — ver Dados § Mascaramento.

Glossário de Domínio

Termos do negócio com significado preciso neste serviço. Quando código, ADR ou conversa divergirem, este glossário é a verdade.

TermoDefinição
Autorização Decisão de permitir ou recusar uma operação de débito antes de ela ser efetivada no saldo. Não é o débito em si — é a aprovação para que ele ocorra.
Liquidação Efetivação financeira da operação após autorização. Acontece em outro serviço; aqui só publicamos o evento de decisão.
Scoring Pontuação 0-100 retornada pelo motor antifraude. Acima do threshold (definido por canal) autoriza; abaixo recusa.
Advice Recomendação do antifraude além do score: APPROVE, DECLINE, REVIEW.
Contingência Modo degradado quando o antifraude está indisponível. Decisão tomada localmente com base em limites configuráveis. Ver Fluxo Contingência.
Estorno Reversão lógica de uma autorização. Não desfaz no domínio — emite nova autorização Estornada com referência ao original.
MCC (Merchant Category Code) ISO 18245. 4 dígitos que classificam o estabelecimento (5411=supermercado, 5812=restaurante, etc.). Usado em regras de contingência.
Idempotência Mesma operação invocada N vezes produz o mesmo resultado. Aqui: mesma Idempotency-Key + payload retorna resposta original cacheada por 24h.
Outbox Tabela que registra eventos a publicar, gravada na mesma transação do agregado. Garante exactly-once lógico.
Correlation ID UUID v4 propagado em todos logs e mensagens. Permite rastrear uma operação end-to-end através de múltiplos serviços.

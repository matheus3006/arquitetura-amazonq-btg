Documentação Técnica

Liquidação Transacional

Microsserviço responsável pela liquidação síncrona de transações de débito entre canais de pagamento e o motor antifraude.

  • .NET 8 + ASP.NET Core
  • Hexagonal Architecture
  • PostgreSQL + Outbox Pattern
  • v0.1.0
▲
Decisão arquitetural

O serviço opera como gateway síncrono entre canais de pagamento e o motor de scoring. Latência máxima de 500ms p95 garantida via Circuit Breaker + Retry + Bulkhead em todas as integrações externas. Contingência local com limites configuráveis quando o motor antifraude está indisponível.
